# 界面截图说明

本目录用于存放“系统构建阶段”的界面截图材料。截图来自当前项目已有运行预览图，主要覆盖控制面板、课程提醒、背包商店、聊天互动、系统设置和桌宠动作资源。

| 序号 | 文件 | 界面/功能 | 简要说明 |
|---|---|---|---|
| 1 | `01_overview_control_panel.png` | 控制面板总览 | 展示北极熊桌宠控制面板的整体布局，包括左侧导航、桌宠在线卡片、状态卡片和今日日志区域。 |
| 2 | `02_course_ocr_page.png` | 课程提醒与课表识别 | 展示课程提醒页面，包含下一节课提醒、课表照片 OCR 识别、文本解析和课程导入入口。 |
| 3 | `03_backpack_shop_page.png` | 背包商店/极地小厨房 | 展示物品卡片、商品展台、库存、金币、投喂和购买功能。 |
| 4 | `04_chat_page.png` | 聊天互动 | 展示聊天页面，包含快捷对话按钮、对话记录区域和输入发送区域。 |
| 5 | `05_settings_page.png` | 系统设置 | 展示桌宠缩放、透明度、置顶、贴边吸附、快捷键和存档管理等系统配置。 |
| 6 | `06_edge_wall_action_frames.png` | 贴边动作帧 | 展示北极熊贴边吸附动作的左右两组序列帧，用于说明桌宠动作资源已经构建。 |
