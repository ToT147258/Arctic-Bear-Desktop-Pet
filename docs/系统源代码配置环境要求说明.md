# 系统源代码、配置文件、环境要求说明

项目名称：北极熊桌面宠物系统

本说明用于“系统构建阶段”中 `系统源代码、配置文件、环境要求` 的提交。

## 1. 源代码内容

核心源代码位于：

```text
main.py
src/
tools/
```

主要模块：

| 路径 | 说明 |
|---|---|
| `main.py` | 程序入口，启动 PySide6 应用。 |
| `src/core/app.py` | 主控模块，负责控制面板、页面切换、系统托盘、快捷键和桌宠调度。 |
| `src/pet/window.py` | 桌宠窗口模块，负责北极熊透明悬浮窗口、动作帧播放、气泡、拖拽和贴边。 |
| `src/data/store.py` | 数据模块，负责状态、等级、好感、背包、任务、课程、聊天和 JSON 存档。 |
| `src/features/` | 功能页面模块，包括状态、课程、动作、聊天、背包、成长和设置页面。 |
| `src/services/` | 服务模块，包括大模型聊天接口和课表 OCR 识别。 |
| `tools/` | 资源处理和动作帧处理辅助脚本。 |

## 2. 必要资源

运行项目需要以下资源：

```text
assets/polar_bear/role/PolarBear/
assets/shop/items/
```

说明：

- `assets/polar_bear/role/PolarBear/` 保存北极熊动作配置和 PNG 序列帧。
- `assets/shop/items/` 保存背包商店食物、道具和礼物图片。

| 文件 | 说明 |

## 4. 环境要求

推荐环境：

| 环境项 | 要求 |
|---|---|
| 操作系统 | Windows 10 / Windows 11 |
| Python | Python 3.10 或更高版本 |
| GUI 框架 | PySide6 6.5.2 |
| 图片处理 | Pillow 10.0.0 或更高版本 |
| OCR 依赖 | pytesseract 0.3.13 或更高版本 |
| OCR 外部程序 | 可选，Tesseract OCR |
| 大模型接口 | 可选，DeepSeek、OpenAI、智谱、通义、Kimi 或 OpenAI 兼容接口 |

依赖安装：

```powershell
pip install -r requirements.txt
```

## 5. 运行方式

命令行运行：

```powershell
cd polar-bear-desktop-pet
python main.py
```

Windows 双击运行：

```text
launch_polar_bear.vbs
```

## 6. 数据存储说明

本项目实际使用 JSON 本地存档，不使用 SQLite 或 MySQL。

运行时自动生成：

```text
data/save.json
```

初始化模板脚本：

```powershell
python docs/database/init_save_json.py
```

默认生成：

```text
data/save.template.json
```

## 7. 打包说明

提交包中不包含以下内容：

- `.git/`
- `.venv/`
- `.local_deps/`
- `__pycache__/`
- 临时截图 `tmp_*.png`
- 运行时个人存档 `data/save.json`
- 诊断和临时视频帧目录

这些内容不是系统源代码、配置文件或环境要求的一部分。
